# 환불 비즈니스 정책

> ⚠️ **검토용 중간 산출물** — [비즈니스_정책_템플릿.md](./비즈니스_정책_템플릿.md)가 잘 작성되었는지 확인하려고 임의의 환불 정책 3건(미사용 7일 이내 전액 환불 / 사용분 공제 + 위약금 10% / 만료·소진 시 환불 불가)으로 채운 문서다. 모든 값은 임의로 정한 값이다.
>
> 상태: 초안 · 버전: v1 · 최종 수정: 2026-10-20 · 승인: 미정
> 검토 메모: 없음(검증용)

### 1. 용어 사전

| 용어 | 코드 식별자 | 정의 |
|---|---|---|
| 이용권 | `Ticket` | 고객이 산 시간권 또는 정기권 1개. 환불의 단위다 |
| 시간권 | `TIME` | 구매한 시간(분)만큼 이용하는 이용권. 예: 10시간권 |
| 정기권 | `PERIOD` | 처음 이용한 날부터 구매한 일수 동안 이용하는 이용권. 예: 30일권 |
| 미사용 | `unused` | 시간권은 남은 시간이 구매한 시간과 같고, 정기권은 아직 처음 이용(활성화)하지 않은 상태. 환불 금액 계산(2-3)에 쓴다 |
| 남은 비율 | `remainingRate` | 구매한 이용량 중 아직 쓰지 않은 비율(%). 계산은 2-2. 사용 이력이 있는 이용권의 환불 금액 계산(2-3)에 쓴다 |
| 위약금 | `penalty` | 사용 이력이 있는 이용권을 환불할 때 빼는 금액. 실결제액 × REF-P02 |
| 환불 신청 시각 | `requestedAt` | 고객이 환불을 신청한 시각. 이 문서의 모든 판정과 기한 비교의 기준이다 |

### 2. 정책 본문

#### 2-1. 환불 판정 (판정형)

##### 평가 순서

1. **대상 여부(T) 규칙**을 `우선순위` 순으로 확인한다. 하나라도 어기면 즉시 거절하고 평가를 중단한다.
2. **가능 조건(C) 규칙**은 전부 평가하고, 어긴 규칙을 모두 기록한다.
3. **대표 사유**는 어긴 규칙 중 `우선순위` 숫자가 가장 작은 규칙으로 한다.
4. **판정 결과**: 대상 여부 위반 → 거절 / 가능 조건 위반 → 거절 / 위반 없음 → 자동 환불(금액은 2-3)

##### 결정 테이블

| 우선순위 | 규칙 ID | 구분 | 조건 | 판정 기준 | 결과 | 거절 사유 코드 | 파라미터 | 예외 승인 |
|---|---|---|---|---|---|---|---|---|
| 10 | REF-T01 | 대상 여부 | 결제가 성공 상태가 아님 | 결제 상태가 결제 대기(`PENDING`)·요청 중(`REQUESTED`)·실패(`FAILED`)·취소(`CANCELLED`) 중 하나 | 거절 | `PAYMENT_NOT_COMPLETED` | - | 불가 |
| 20 | REF-T02 | 대상 여부 | 이미 환불됨 | 같은 이용권에 환불 완료(§6) 기록이 있음 | 거절 | `ALREADY_REFUNDED` | - | 불가 |
| 10 | REF-C01 | 가능 조건 | 정기권 유효기간이 지남 | 정기권이고, 환불 신청 시각이 만료일 다음 날 0시 이후 | 거절 | `TICKET_EXPIRED` | - | 불가 |
| 20 | REF-C02 | 가능 조건 | 시간권 남은 시간이 없음 | 시간권이고, 남은 시간이 0분 | 거절 | `NO_REMAINING_TIME` | - | 불가 |

- REF-T01, REF-T02는 정책 3건에는 없지만, 환불 판정에 기본으로 필요한 대상 여부 규칙이라 추가했다.
- 정기권의 만료일은 처음 이용한 날 + 구매한 일수다. 만료일 당일까지는 이용할 수 있는 것으로 본다. 아직 처음 이용하지 않은 정기권은 만료일이 없으므로 REF-C01을 위반하지 않는다.

#### 2-2. 남은 비율 산정

| 상품·상태 | 남은 비율 계산 |
|---|---|
| 시간권 | 남은 시간 ÷ 구매한 시간 × 100 |
| 정기권(처음 이용 전) | 100% |
| 정기권(처음 이용 후) | 만료일까지 남은 일수 ÷ 구매한 일수 × 100. 남은 일수의 하루 미만은 버린다 |

#### 2-3. 환불 금액 (계산형)

| 항목 | 정책 |
|---|---|
| 기준 금액 | 이용권별 실결제액(할인 적용 후 금액) |
| 계산식 | 미사용이고 구매 후 REF-P01 이내 → 기준 금액 전액<br>사용 이력 있음 → 기준 금액 × 남은 비율(2-2) − 기준 금액 × REF-P02<br>미사용이고 구매 후 REF-P01 경과 → `[결정 필요 D-01]` |
| 상한 / 하한 | 상한은 기준 금액, 하한은 0원(계산 결과가 0원보다 적으면 0원) |
| 횟수 | 이용권 1개당 환불 1회 |
| 반올림·절사 | `[결정 필요 D-02]` |
| 미정 | D-01, D-02 — §8 미결 항목 참고 |

### 3. 파라미터 (기준값)

| 파라미터 ID | 정책 버전 | 적용 대상 | 값 | 시행일 | 근거 |
|---|---|---|---|---|---|
| REF-P01 | v1 | 전체 | 7일 | 2026-10-20 | 임의(검증용) |
| REF-P02 | v1 | 전체 | 10% | 2026-10-20 | 임의(검증용) |

**적용 원칙**: 구매 시점의 정책 버전을 적용한다.

### 4. 거절 사유 코드

| 거절 사유 코드 | 규칙 ID | 고객 안내 문구 |
|---|---|---|
| `PAYMENT_NOT_COMPLETED` | REF-T01 | 결제가 완료되지 않은 주문입니다. |
| `ALREADY_REFUNDED` | REF-T02 | 이미 환불된 이용권입니다. |
| `TICKET_EXPIRED` | REF-C01 | 유효기간({expiresAt})이 지나 환불할 수 없습니다. |
| `NO_REMAINING_TIME` | REF-C02 | 남은 이용 시간이 없어 환불할 수 없습니다. |

- 문구의 `{expiresAt}`는 판정할 때 기록한 만료일에서 가져온다.

### 5. 예외 승인

예외 승인이 가능한 규칙은 없다(결정 테이블의 예외 승인 열이 모두 `불가`).

### 6. 환불 완료

- 결제 수단으로 결제 취소가 확정된 시점을 환불 완료로 본다.
- 완료 시 이용권이 소멸하고, 정산에 환불이 반영된다.
- 취소가 확정되기 전에는 "처리 중"이며, 같은 이용권의 새 환불 신청을 받지 않는다.
