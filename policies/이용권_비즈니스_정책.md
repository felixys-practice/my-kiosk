# 이용권 비즈니스 정책

> ⚠️ **검토용 중간 산출물**
>
> 상태: 초안 · 버전: v0.2 · 최종 수정: 2026-10-20 · 승인: 미정
> 규칙 ID 약어: TKT
> 검토 메모: 없음

### 1. 용어 사전

| 용어 | 정의 |
|---|---|
| 이용권 | 고객이 구매한 좌석 이용 권리 1개 |
| 이용권 종류 | 이용권을 고정석과 자유석으로 나누는 구분. 구매할 때 정해진다. 시간권·정기권 구분과는 별개다(예: 고정석 시간권, 자유석 정기권) |
| 고정석 이용권 | 정해진 좌석 하나만 쓸 수 있는 이용권 |
| 자유석 이용권 | 빈 좌석이면 어디든 쓸 수 있는 이용권 |
| 이용 중 | 고객이 이용권으로 좌석을 쓰고 있는 상태. 이용 시작부터 이용 종료 전까지다 |
| 이용 시작 요청 시각 | 고객이 이용권으로 이용(입실)을 시작하려고 요청한 시각. 이 문서의 판정 기준 시각이다 |

### 2. 정책 본문

#### 2-1. 이용 시작 판정 (판정형)

##### 평가 순서

1. **대상 여부(T) 규칙**을 `우선순위` 순으로 확인한다. 하나라도 어기면 즉시 거절하고 평가를 중단한다.
2. **가능 조건(C) 규칙**은 전부 평가하고, 어긴 규칙을 모두 기록한다.
3. **대표 사유**는 어긴 규칙 중 `우선순위` 숫자가 가장 작은 규칙으로 한다.
4. **판정 결과**는 결정 테이블의 결과 코드로 정하고, 결과별로 일어나는 일은 아래 **판정 결과** 표를 따른다.

##### 결정 테이블

| 우선순위 | 규칙 ID | 구분 | 조건 | 판정 기준 | 결과 코드 | 거절 사유 코드 | 파라미터 | 예외 승인 |
|---|---|---|---|---|---|---|---|---|
| 10 | TKT-T01 | 대상 여부 | 같은 종류의 이용권을 이미 이용 중 | 같은 고객에게 이용 중인 이용권이 있고, 그 이용권의 종류(고정석/자유석)가 이번에 이용을 시작하려는 이용권과 같음 | `REJECTED` | `SAME_TYPE_TICKET_IN_USE` | - | 불가 |
| - | - | - | 어긴 규칙 없음 | - | `USAGE_STARTED` | - | - | - |

- 판정 시점: 이용 시작 요청 시각.
- 이용권은 동시에 하나만 쓸 수 있다. 다만 종류가 다르면 함께 쓸 수 있으므로, 고정석 이용권 1개와 자유석 이용권 1개까지 동시에 이용할 수 있다.

##### 판정 결과

| 결과 코드 | 판정 결과 | 일어나는 일 | 시점 |
|---|---|---|---|
| `REJECTED` | 거절 | 이용을 시작하지 않는다. 이용 중인 이용권과 이용권 상태에는 변화가 없다. 안내 문구(§4)를 보여준다 | 이용 시작 요청 즉시 |
| `USAGE_STARTED` | 이용 시작 | 이 이용권으로 좌석 이용을 시작한다. 이 이용권은 이용 중이 된다 | 이용 시작 요청 즉시 |

### 3. 파라미터 (기준값)

현재 판정에 쓰는 기준값은 없다.

### 4. 거절 사유 코드

| 거절 사유 코드 | 규칙 ID | 고객 안내 문구 |
|---|---|---|
